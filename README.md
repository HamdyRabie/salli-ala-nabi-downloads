# صلّ على النبي ﷺ

تطبيق أندرويد عربي للتذكير بالصلاة على النبي ﷺ، يعمل بدون إنترنت.

## تحميل التطبيق

**[اضغط هنا لتحميل التطبيق — الإصدار 1.1](https://github.com/HamdyRabie/salli-ala-nabi-downloads/releases/download/v1.1/SalliAlaNabi-1.1.apk)**

[صفحة الإصدار وملفات التحميل](https://github.com/HamdyRabie/salli-ala-nabi-downloads/releases/tag/v1.1)

التحميل متاح للجميع بدون حساب GitHub. يدعم التطبيق Android 8.0 أو أحدث.

## التثبيت والاستخدام

1. حمّل ملف `SalliAlaNabi-1.1.apk` وافتحه لتثبيته. يمكن تثبيته كتحديث فوق النسخة السابقة الأصلية.
2. اسمح بالإشعارات، ثم اختر مدة التذكير التي تبدأ من 10 دقائق.
3. عند استخدام خيار **الصوت من سماعة الهاتف**، اسمح بالتنبيهات الدقيقة واضبط مستوى صوت المنبّه. دعم توجيه الصوت مع البلوتوث يختلف حسب الجهاز.

هذه الصفحة مخصصة لتنزيل نسخة التطبيق.
